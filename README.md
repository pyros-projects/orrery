# orrery

A prompt language whose every expansion records which choices produced which
text, plus a galaxy of images that learns from your verdicts and steers the next
batch toward the regions you like.

```
$hero = __animal__
$hero in a {misty|burning|frozen:3} forest, {1-2$$__style__}
: x8 seed=100
```

Status: concept. Read [docs/concept.md](docs/concept.md).
